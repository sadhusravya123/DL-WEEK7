# LSTM Next Word Prediction

## Aim

To implement an LSTM network for predicting the next word using sequential text data.

## Dataset

Reuters dataset from TensorFlow/Keras containing 11,228 news articles across 46 categories.

## Technologies

* Python
* TensorFlow / Keras
* NumPy
* Matplotlib
* Seaborn

## Methodology

1. Load the Reuters dataset.
2. Preprocess and tokenize text.
3. Generate input sequences and apply padding.
4. Build and train the LSTM model.
5. Predict the next word.
6. Evaluate performance using accuracy and a confusion matrix.

## Result

Successfully implemented an LSTM model for next-word prediction using sequential text data.
